# Support

Before opening an issue, run:

```bash
evalpilot doctor --json
```

Search existing GitHub issues, then use the bug or feature template. Include the EvalPilot version, Node version, operating system, the visible error, and reproducible steps.

Do not attach source code, `.env` files, tokens, Agent conversations, unredacted screenshots, Trace archives, or the full `~/.evalpilot-local` directory. This Public Alpha is community-supported; no response-time guarantee is provided.
